# Shotation skills

Agent skills for [Shotation](https://shotation.com): capture your app's real screens and turn
them into App Store screenshot sets.

```bash
npx skills add arnenoori/shotation-skills
```

- `shotation` runs the CLI (`npx shotation@latest`): capture web, iOS, and Android screens,
  score UI coverage, and export store-size sources.
- `shotation-screenshot-director` plans and renders a store listing: slot order, one headline
  per card, a set-level design (device grid, background system, shots, stitched seams), and
  named directions to compare. Card design runs through Codex (`codex login`) or an image API
  key.

These files are published from the Shotation source, so changes land there first; issues are
welcome here.
