# Copy Patterns

Screenshot copy should be short, specific, and visibly proven by the source UI.

## Headline Patterns

Good:

- Plan every workout from one screen
- Compare swings side by side
- See the exact drill to fix next
- Ship screenshots from real app states
- Private by default, editable when needed

Weak:

- The best app for everyone
- A powerful experience
- Everything you need
- Simple. Fast. Beautiful.
- Next-generation productivity

## Subheadline Patterns

Good:

- Built from your latest capture run, with blocked states flagged before export.
- Three related screens show the full checkout path.
- Settings, permissions, and plan limits stay visible for review.
- Apple and Google targets export from the same saved storyboard.

Weak:

- Try it today and see the difference.
- Designed for modern users.
- Works like magic.
- Save time and be more productive.

## Review Rules

- Keep headlines under roughly 7 words unless the layout clearly supports more.
- Let the UI carry the feature proof. Do not explain what the image already shows.
- Name the concrete feature, state, or outcome.
- Avoid absolute claims unless there is visible or cited proof.
- One message per card: a headline only, no subheadline. If it needs a second line of explanation, the headline or the screen is wrong.
